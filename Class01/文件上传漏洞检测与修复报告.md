### 1.3 安全测试

#### 1.3.1 任意文件上传测试

**测试目的**：检查系统是否限制上传文件类型。  
**测试方法**：分别上传 jpg、png、txt、html、py、php 等多种类型的文件，观察是否允许上传以及文件是否能够通过 URL 访问。

**测试结果**（修复前）：

| 上传文件 | 后缀 | 结果 | 风险评估 |
|:---------|:----:|:----:|:---------|
| 图片文件 | `.jpg` | ✅ 上传成功 | 正常 |
| 图片文件 | `.png` | ✅ 上传成功 | 正常 |
| 文本文件 | `.txt` | ✅ 上传成功 | ⚠️ 不应允许 |
| 网页文件 | `.html` | ✅ 上传成功 | 🔴 **可执行 XSS** |
| Python脚本 | `.py` | ✅ 上传成功 | 🔴 源码泄露 |
| PHP脚本 | `.php` | ✅ 上传成功 | 🔴 服务器解析风险 |
| 可执行文件 | `.exe` | ✅ 上传成功 | 🟠 恶意软件分发 |

**结论**：服务端**未限制上传文件类型**，存在严重的任意文件上传漏洞。

**风险说明**：
- `.html` 文件能够上传并通过 URL 直接访问，浏览器会解析其中的 JavaScript 脚本，**存在存储型 XSS 攻击风险**
- `.py` 文件可直接被下载查看源码
- 所有恶意文件均可以通过公开 URL 被访问和传播

#### 1.3.2 文件名安全测试

**测试目的**：检查系统是否对文件名做安全处理。  
**测试内容**：

| 测试项 | 测试文件名 | 结果（修复前） |
|:-------|:-----------|:--------------:|
| 中文文件名 | `头像.jpg` | ✅ 保存成功 |
| 特殊字符 | `test!@#$.png` | ✅ 保存成功 |
| 超长文件名 | `A...x200.png` | ✅ 保存成功 |
| 路径穿越 | `../../../app.py` | ✅ 保存成功 |
| 重复文件名（第1次） | `avatar.png` | ✅ 保存成功 |
| 重复文件名（第2次） | `avatar.png` | ✅ **覆盖原文件** |

**风险说明**：
- 路径穿越文件名可能覆盖服务器上的关键文件
- 重复上传同名文件**直接覆盖**原文件，无冲突处理机制
- 特殊字符和超长文件名可能导致文件系统错误

#### 1.3.3 文件大小测试

**测试目的**：验证 `MAX_CONTENT_LENGTH` 限制是否生效。  
**测试结果**：

**结论**：系统已限制单次上传大小，但仍建议增加上传频率限制，避免资源耗尽。

## 2. 文件上传漏洞分析与修复

### WEB-UP-001：任意文件上传

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | WEB-UP-001 |
| **CWE 编号** | CWE-434：Unrestricted Upload of File with Dangerous Type |
| **OWASP 分类** | A03:2021 – Injection |
| **风险等级** | 🔴 **严重** |

#### 漏洞代码（修复前）

```python
# app.py 第 329-332 行
filename = file.filename
save_path = os.path.join(UPLOAD_FOLDER, filename)
file.save(save_path)
file_url = url_for("static", filename=f"uploads/{filename}")
```

#### 漏洞原因

服务端对上传文件的**类型、后缀、MIME、文件内容完全不做任何检查**。任何文件（包括 `.html`、`.php`、`.py`、`.exe`）均可上传并通过 URL 直接访问。

#### 风险影响

| 攻击场景 | 危害 |
|:---------|:-----|
| 上传 `.html` 含恶意 JavaScript | **存储型 XSS**，窃取用户 Cookie |
| 上传 `.py` 脚本 | 源码泄露 |
| 上传 `.php` webshell | 远程代码执行（服务器支持 PHP 解析时） |
| 上传恶意 `.exe` | 诱导用户下载执行 |

#### 修复代码（修复后）

```python
# 三层校验：
# 1. 后缀白名单
ALLOWED_EXTENSIONS = {"jpg", "jpeg", "png", "gif", "bmp", "webp"}

def allowed_file(filename):
    return "." in filename and \
           filename.rsplit(".", 1)[1].lower() in ALLOWED_EXTENSIONS

# 2. MIME 类型校验
ALLOWED_MIMETYPES = {"image/jpeg", "image/png", "image/gif", "image/bmp", "image/webp"}
if file.mimetype not in ALLOWED_MIMETYPES:
    return render_template("upload.html", error="不支持的文件类型")

# 3. Magic Number 校验
def valid_magic_number(file_obj):
    header = file_obj.read(16)
    file_obj.seek(0)
    return any(header.startswith(magic) for magic, _ in MAGIC_NUMBERS)

if not valid_magic_number(file):
    return render_template("upload.html", error="文件内容不是有效的图片格式")
```

### WEB-UP-004：文件内容（Magic Number）校验缺失

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | WEB-UP-004 |
| **CWE 编号** | CWE-434 |
| **风险等级** | 🟠 **高危** |

#### 漏洞代码（修复前）

```python
file.save(save_path)  # 直接保存文件内容，未做任何内容检查
```

#### 攻击向量

攻击者可将恶意脚本**伪装成图片**（改后缀为 `.png`/`.jpg`），绕过仅基于后缀的校验：

| 伪装的请求 | 实际内容 | 绕过方式 |
|:-----------|:---------|:---------|
| `avatar.png` | `<script>alert('XSS')</script>` | 改后缀为 .png |
| `photo.jpg` | `<?php system($_GET['cmd']); ?>` | 改后缀为 .jpg |

#### 修复代码（修复后）

```python
# 第 51-57 行：Magic Number 定义
MAGIC_NUMBERS = [
    (b"\xff\xd8\xff", "jpeg"),           # JPEG 文件头
    (b"\x89PNG\r\n\x1a\n", "png"),       # PNG 文件头
    (b"GIF87a", "gif"), (b"GIF89a", "gif"),  # GIF 文件头
    (b"BM", "bmp"),                      # BMP 文件头
    (b"RIFF", "webp"),                   # WebP 文件头
]

# 第 138-142 行：校验函数
def valid_magic_number(file_obj):
    header = file_obj.read(16)    # 读取前 16 字节
    file_obj.seek(0)              # 重置文件指针
    return any(header.startswith(magic) for magic, _ in MAGIC_NUMBERS)

# 第 370-373 行：调用校验
if not valid_magic_number(file):
    return render_template("upload.html", error="文件内容不是有效的图片格式")
```

**Magic Number 对照表**：

| 图片格式 | Magic Number（十六进制） | 文件头（前 12 字节） |
|:--------:|:------------------------|:--------------------|
| JPEG | `FF D8 FF` | `\xff\xd8\xff...` |
| PNG  | `89 50 4E 47 0D 0A 1A 0A` | `\x89PNG\r\n\x1a\n...` |
| GIF  | `47 49 46 38 37/39 61` | `GIF87a` / `GIF89a` |
| BMP  | `42 4D` | `BM...` |
| WebP | `52 49 46 46` + `57 45 42 50` | `RIFF....WEBP` |


| `../app.py` | `app.py` |
| `头像.jpg` | `头像.jpg` |
| `<script>.html` | `script_.html` |

### WEB-UP-007：上传目录安全性

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | WEB-UP-007 |
| **CWE 编号** | CWE-434 |
| **风险等级** | 🟡 **中危** |

#### 修复前

```python
UPLOAD_FOLDER = os.path.join("static", "uploads")
# 上传文件可通过 /static/uploads/<文件名> 直接公开访问
```

**风险**：上传目录在 `static/` 下，`.html` 文件会被浏览器直接解析执行。

#### 修复后

```python
# 第 42 行：移出 static 目录
UPLOAD_FOLDER = os.path.join(os.path.dirname(os.path.abspath(__file__)), "uploads")

# 第 400-410 行：通过单独路由提供访问，添加安全响应头
@app.route("/uploads/<filename>")
@login_required
def uploaded_file(filename):
    from flask import send_from_directory
    response = send_from_directory(app.config["UPLOAD_FOLDER"], filename)
    response.headers["X-Content-Type-Options"] = "nosniff"  # 防止 MIME 嗅探
    response.headers["Content-Disposition"] = f"inline; filename=\"{filename}\""
    return response
```
