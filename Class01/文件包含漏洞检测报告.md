## 3. 文件包含漏洞测试

### LFI-001：本地文件包含 —— 路径穿越（严重）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-001 |
| **漏洞名称** | 本地文件包含（Local File Inclusion）—— 路径穿越 |
| **漏洞类型** | 文件包含漏洞（LFI） |
| **CWE 编号** | CWE-22：Improper Limitation of a Pathname to a Restricted Directory ('Path Traversal') |
| **OWASP 分类** | A01:2021 – Broken Access Control |
| **风险等级** | 🔴 **严重** |
| **漏洞位置** | `app.py` 第 562-596 行 `/page` 路由 |

#### 漏洞代码

```python
# app.py 第 562-596 行
@app.route("/page")
def dynamic_page():
    name = request.args.get("name", "")       # ← 用户输入直接使用
    page_content = None
    error = None

    if name:
        # 使用拼接字符串的方式构建文件路径（不做路径校验）
        page_path = os.path.join(app.root_path, "pages", name)  # ← 直接拼接

        if os.path.isfile(page_path):
            with open(page_path, "r", encoding="utf-8") as f:
                page_content = f.read()                         # ← 读取任意文件
        else:
            # 尝试加上 .html 后缀
            page_path_html = page_path + ".html"
            if os.path.isfile(page_path_html):
                with open(page_path_html, "r", encoding="utf-8") as f:
                    page_content = f.read()
            else:
                error = "页面不存在"
```

```html
{# templates/index.html 第 6 行 #}
{{ page_content | safe }}   {# ← 直接渲染不做转义 #}
```

#### 漏洞详情

`/page` 路由接收用户通过 URL 参数 `name` 传入的文件名，直接拼接到文件路径中 `os.path.join(app.root_path, "pages", name)`，然后读取并返回文件内容。代码存在以下问题：

| 问题 | 说明 |
|:-----|:------|
| **无路径校验** | 未检查 `name` 中是否包含 `../` 等路径穿越字符 |
| **无路径规范化** | 未使用 `os.path.abspath` 或 `os.path.realpath` 规范化路径 |
| **无认证保护** | 未添加 `@login_required`，未登录也可访问 |
| **无文件类型限制** | 可读取 `.py`、`.db`、`.css`、`.html` 等任意类型文件 |
| **安全过滤器使用** | `{{ page_content \| safe }}` 直接渲染不转义 |

攻击者利用 `../` 实现目录跳转，可读取 `pages/` 目录以外的任意文件。

#### 攻击方法与演示

##### 攻击向量 1：读取应用源码（app.py）

| 属性 | 内容 |
|:-----|:------|
| **攻击方式** | 路径穿越读取 Python 源码 |
| **恶意输入** | `name=../app.py` |
| **构建路径** | `os.path.join(root_path, "pages", "../app.py")` → `root_path/app.py` |

**攻击请求**：

### LFI-002：未授权访问（缺失认证）

| 属性 | 内容 |
|:-----|:------|
| **漏洞编号** | LFI-002 |
| **漏洞名称** | `/page` 路由未授权访问 |
| **漏洞类型** | 认证缺失 |
| **CWE 编号** | CWE-306：Missing Authentication for Critical Function |
| **风险等级** | 🟠 **高危** |
| **漏洞位置** | `app.py` 第 563 行 `def dynamic_page():` — **无 `@login_required` 装饰器** |

#### 漏洞代码

```python
@app.route("/page")
def dynamic_page():        # ← 缺少 @login_required 装饰器
    name = request.args.get("name", "")
    ...
    with open(page_path, "r", encoding="utf-8") as f:
        page_content = f.read()       # ← 未登录也可执行
```

对比其他路由（如 `/upload`、`/profile` 已有 `@login_required`）。

#### 攻击演示

**无需登录**，直接发送请求即可读取任意文件：

```
GET /page?name=../app.py HTTP/1.1
（无 Cookie）
```

**攻击结果**（成功 ✅）：
```
未登录状态下成功读取 app.py 源码！
```
