## 2. 漏洞修复及修复后测试

### 2.1 修复代码

#### 修复后 `app.py`（`/page` 路由）

```python
@app.route("/page")
@login_required                                    # 修复 LFI-BASIC-001：添加登录认证
def dynamic_page():
    name = request.args.get("name", "")
    page_content = None
    error = None

    if name:
        # 修复 LFI-ABSOLUTE-001 & LFI-PATH-001：规范化路径并校验前缀
        pages_dir = os.path.realpath(os.path.join(app.root_path, "pages"))
        requested_path = os.path.realpath(os.path.join(pages_dir, name))

        # 校验：目标文件必须在 pages/ 目录内
        if not requested_path.startswith(pages_dir):
            error = "页面不存在"                     # 拦截所有路径穿越和绝对路径注入
        elif os.path.isfile(requested_path):
            with open(requested_path, "r", encoding="utf-8") as f:
                page_content = f.read()
        else:
            requested_path_html = requested_path + ".html"
            if os.path.isfile(requested_path_html):
                with open(requested_path_html, "r", encoding="utf-8") as f:
                    page_content = f.read()
            else:
                error = "页面不存在"

    ...
    return render_template("index.html", user_info=user_info,
                           page_content=page_content, page_error=error)
```

### 3.5 关键代码对比

#### 路径构建 —— 修复前后

```python
# 修复前（漏洞代码）
page_path = os.path.join(app.root_path, "pages", name)
# os.path.join('/app/pages', '/etc/shadow') → '/etc/shadow'      ← 绝对路径注入
# os.path.join('/app/pages', '../app.py')   → '/app/pages/../app.py' ← 路径穿越

# 修复后（安全代码）
pages_dir = os.path.realpath(os.path.join(app.root_path, "pages"))
requested_path = os.path.realpath(os.path.join(pages_dir, name))
# os.path.realpath 会解析所有 ../ 和软链接
# 再通过 startswith 校验必须在 pages/ 内
if not requested_path.startswith(pages_dir):
    error = "页面不存在"
```

**`os.path.realpath()` 的防护效果**：

| 输入 `name` | `os.path.join` 结果 | `os.path.realpath` 结果 | 是否在 pages/ 内 |
|:------------|:--------------------|:------------------------|:----------------:|
| `help` | `/app/pages/help` | `/app/pages/help` | ✅ 是 |
| `nonexistent` | `/app/pages/nonexistent` | `/app/pages/nonexistent` | ✅ 是（不存在） |
| `../app.py` | `/app/pages/../app.py` | `/app/app.py` | **❌ 否 → 拦截** |
| `/etc/shadow` | `/etc/shadow` | `/etc/shadow` | **❌ 否 → 拦截** |
| `//etc/passwd` | `//etc/passwd` | `/etc/passwd` | **❌ 否 → 拦截** |
